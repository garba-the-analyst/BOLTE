# Philosophy, Model, Values, Ethics

## Core philosophy
"All problems are solved when you put things together."
Africa's challenges cannot be solved by one discipline, institution, or person. Progress comes from bringing ideas, people, knowledge, resources, and technology together.

## The BOLTE Model
PROBLEM → IDEA → RESEARCH → ENGINEERING → PROTOTYPE → TESTING → IMPROVEMENT → DEPLOYMENT → IMPACT
Bigger cycle: Nigeria → African Capability → African Technological Independence.

## Values
1. Sovereignty by capability (build, don't just buy)
2. Multidisciplinary building
3. Honest engineering (admit limits, risks, TRL)
4. Local maintainability
5. Talent multiplication

## Ethics guardrails (defense work)
- Lawful and legitimate users only; comply with Nigerian law and export controls.
- Defensive/situational-awareness posture; no indiscriminate harm enablers.
- Human decision-maker in the loop for operational judgments (e.g. STCA is advisory).
- Safety, testing discipline, and documentation before deployment.
- Any partnership with security institutions requires both co-founders' written approval.
