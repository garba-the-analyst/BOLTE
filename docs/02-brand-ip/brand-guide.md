## Logo system (final)
- **Mark:** bolt piercing a hexagonal "C" — navy `#0A1428` on light, white `#FFFFFF` on dark.
- **Lockup:** `B⚡LTE` wordmark where O = bolt-hex mark, E = sigma-style cut. Two versions:
  - Dark-bg: white wordmark on deep navy `#0A1428`.
  - Light-bg: navy wordmark on white; bolt-hex may render in steel grey `#5B6B7F`.
- **Watermark:** oversized low-opacity lockup behind content (decks, covers) — never behind body text.
- Logo files live in `assets/logo-placeholder/bolte-*.png` (see `README.md` there for exact names; v0.3 PNGs converted from `assets/logos/` JPEGs).

## Wordmark fallback (use only if logo files missing)
- Text: `BOLTE` — all caps, bold, letter-spacing 0.08em. Never `Bolte`/`bolte` in headings.
- Placeholder lockup: `BOLTE` + subline `CORPORATE DIRECTION` or `Indigenous Technology for Nigeria & Africa`.
- Clearspace: height of "B" on all sides. Min width: 120px digital / 30mm print.

## Colors (final)
- Primary navy: `#0A1428` (backgrounds, light-bg wordmark)
- Accent blue: `#2E86DE` (links, rules, highlights)
- Steel grey: `#5B6B7F` (bolt-hex on light lockup, muted graphics)
- Text on dark: `#FFFFFF` / muted `#B8C2CC`
- Text on light: `#0A1428` / muted `#3D4A5C`
- Danger/alert: `#E63946` (demos only)

## Typography (interim system stack)
- Headings: bold sans (Inter / system-ui) until brand font chosen.
- Body: system-ui, 16–18px, line-height 1.6. Deck body ≥24pt.
- Mono for specs: ui-monospace.

## Usage rules
- Dark-bg lockup on navy/black only; light-bg lockup on white/light only — never cross.
- Watermark opacity ≤12%; never behind body text or tables.
- No stretching, gradients, recoloring, or drop shadows on logo; clearspace = height of "B".
- Min sizes: lockup 120px digital / 30mm print; mark alone 32px / 10mm.
- Photography/diagrams over stock clichés; one idea per slide.
- Logo-coming-soon box retired — real lockups/marks live; swap in SVG/transparent masters when delivered + update this file + CHANGELOG.
