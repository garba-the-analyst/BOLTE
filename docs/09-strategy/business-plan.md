# Business Plan (Lean v0.1)

## 1. Identity
See Canon. Pre-CAC collective; converting to Ltd.

## 2. Problem
Nigeria over-relies on foreign tech for security-critical functions; secondary aerodromes/tactical sites underserved; talent leaks for lack of build opportunities.

## 3. Solution
Indigenous R&D → prototypes → deployable systems. Flagship AeroPulse-NG proves model: sovereign, offline, locally maintainable surveillance at ~1% of import cost.

## 4. Customers (first)
NAMA-style civil operators of unjustified-radar aerodromes; defence/tactical users needing air-gapped picture; training institutions; later: MRO, airport logistics, agri/energy adapters.

## 5. Model
Pilots + hardware kits + integration/support + training; IP licensing for dual-use cores; grants/prizes (incl. NDAIE) into treasury (50% retained).

## 6. Go-to-market
NDAIE visibility → field-trial partner [TBD] → trial report → paid pilots → facility + CAC → scale. Website + docs + exhibition drive credibility.
