# Signing Checklist (procedure, not advice)

## Before signing day
- [ ] A3 effective date fixed; G1 term (default 12 months from effective date, auto-renew to CAC Ltd).
- [ ] All 7 names + addresses + ID types collected (G2); seats assigned (F1–F2).
- [ ] Prior IP per person listed or "none" (G4 → Schedule A).
- [ ] CoI pre-checks done (NASS judges/organisers/teams); AI-use log ready.
- [ ] Witness arranged (G5 default: one independent adult witness per signature).
- [ ] Lawyer review booked (G6); print 7 MOU + 7 NDA + 7 IP sets + cap-table.

## Signing day order (per person)
1. Verify ID → Stage 2 ack boxes ticked → sign NDA (2 originals).
2. Sign IP assignment + Schedule A + CoI declaration (2 originals).
3. Sign MOU + witness signs + dates (2 originals: member + BOLTE file).
4. Update `00-index.md` status table; open cap-table row; grant ledger view.

## After
- [ ] Sealed storage + scanned PDFs (custodian `[TBD]`); access log.
- [ ] Treasury ledger live; spending threshold `[TBD ₦]` enforced (dual founders above).
- [ ] Calendar: NDA expiry 3 yrs / trade secrets 5 yrs; MOU renewal vs CAC conversion.
- [ ] Any new joiner repeats full order; any exit triggers return-of-materials + surviving-clauses letter.
