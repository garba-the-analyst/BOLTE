# Code of Conduct

Applies to all members, contributors, competition supporters.

1. Professional, respectful conduct toward organisers, judges, participants, attendees.
2. Original work only. No plagiarism, fabrication, misrepresentation. Credit sources/tools/contributors; IEEE style for papers.
3. Disclose significant generative-AI use; declare conflicts of interest early.
4. Protect confidential info; no public disclosure of unpublished inventions without approval.
5. Safety first in labs/field tests; lawful activity only.
6. Violations: warning → suspension → removal + forfeiture of pending distributions; NASS-level violations risk team disqualification.

Report concerns in writing to both co-founders; handled confidentially.
