# Roles, Responsibilities, Expectations

## All members
- Uphold Canon + Code of Conduct; protect confidential info; assign IP per IP agreement.
- Weekly contribution (build, research, or ops) + demo-able progress; honest status (done / blocked / next).
- No side disclosure of BOLTE inventions without approval; declare conflicts immediately.
- Maintain lab/equipment safety; document work so others can reproduce.

## Co-founders (additional)
- Set direction, approve Canon changes, partnerships, spending, publications, competition entries.
- Mentor members; ensure treasury transparency; lead legal conversion to Ltd.

## Treasurer (B1, 7.5% pool weight)
- Maintain income/expense ledger, receipts, monthly statement to all members.
- Custody of treasury (50%); dual approval with one co-founder for disbursements.
- Own cap-table/distribution sheet; flag shortfalls early.

## Product/Operations Manager (B2, 7.5% pool weight)
- Own roadmap + NDAIE delivery (deck, video, rehearsals, logistics).
- Run weekly reviews, risk log, QA on builds/demos.
- Coordinate exhibition, travel, comms.

## Members C/D/E (5% each)
- Own assigned subsystem or function; write tests/docs; support demos.
- Reviews, field trials, outreach as assigned.

## Commitment & exit
- Minimum active participation: [TBD: e.g. 8 hrs/week + weekly review] — tune to student schedules.
- Inactivity 4 weeks without notice → review; 8 weeks → offboarding + distribution pro-rata.
- On exit: return materials, confirm confidentiality + IP assignment survive exit; unvested/undistributed share returns to treasury.
- Removal for misconduct (plagiarism, dishonesty, breach) per MOU + Code of Conduct.
