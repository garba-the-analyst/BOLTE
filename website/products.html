What we build

One bench prototype, four spec-only concepts, one programme-scale concept. Every stage stated honestly. Source: docs/04-products/functional-overview.md.

TRL honesty: AeroPulse-NG is a bench prototype (TRL 4–5). ASOL, DAFV, C4ISR-DFE, TBR-HS are spec-only concepts (TRL 1–2) — no code, gated until AeroPulse trial + treasury review. HFP-X is a programme-scale concept (BL-0.0, structure only) on a separate evidence-gated track.

AeroPulse-NG Prototype v2.4.0 · TRL 4–5

Users
Secondary-aerodrome operators, tactical air-picture users, trainees.
Does
1090 MHz ADS-B/Mode S + 131.55 MHz ACARS ingest → decode → 6-state filter + dead reckoning → STCA advisory (Doc 4444 5NM/1000ft) → 3-source weather fusion → defence overlays (7500/7600/7700, dark/silence, geofence, intercept solver) → dual-window display + headless console + DuckDB record + synthetic-feed demo.
Offline
Air-gapped by contract; sim == live path; deterministic replay.
Limits
Synthesized FFT now, real RTL-SDR I/Q next; single-site; cooperative targets primarily.

ASOL — Armory Shift & Ordnance Log Concept · spec-only

Users
Armorer, duty officer, auditor.
Does
Register → check-out (dual-custodian + fresh liveness) → check-in → shift handover (dual signatures + count reconcile) → quarantine/dispose → signed export + verify_chain.
Offline
SQLCipher AES-256, hash-chained journal, removable-media export.

DAFV — Defense Asset & Firmware Verifier Concept · spec-only

Users
Depot receiving-dock auditor.
Does
Acquire (JTAG/UART/USB/file) → BLAKE3 + SHA-256 → Ed25519 manifest verify → RFID bind → PASS/FAIL/INCONCLUSIVE + evidence → signed report. Never auto-flashes.
Offline
Static Rust binary, local trust roots.

C4ISR-DFE — Data Fusion Engine Concept · spec-only

Users
Vehicle/bunker command.
Does
ADS-B / UAV coords / RF bearings / GPS tracks → TrackReport → associate/track/coast → events → offline MBTiles map → protobuf UDP delta mesh → snapshot export.
Offline
On-device tiles, store-and-forward, sequenced idempotent deltas.

TBR-HS — Biometric Radar & Health System Concept · safety-gated

Users
Squad + medic (advisory only).
Does
BLE/UWB → Butterworth + FFT → vitals (STABLE/WATCH/URGENT) + radar motion (NO_MOTION/POSSIBLE/MOTION + arc/SNR) → Ed25519 IFF → 60–180° HUD + encrypted log.
Safety
Phantoms before people; no human contact until safety/ethics review + both-founders sign-off.

HFP-X — Human Flight Platform Programme concept · BL-0.0

Users
Test pilots (long-term), ground crew, ground station, regulators, test range.
Does
Prone/semi-prone piloted VTOL/transition flight — vertical take-off → hover → transition ↔ cruise → landing across 15 mission modes + emergency recovery; distributed jet propulsion (arm/rear-torso/ankle modules), fly-by-wire, smart helmet/HUD, continuous ground-station telemetry.
Programme
34-volume doc tree + separate unmanned-first MVP demonstrator; human flight only after unmanned hover/transition/cruise evidence gates.
Limits
All performance values TBD, no design selected, nothing claimed standards-compliant.
